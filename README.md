# CCF CSP 认证备考记录

本仓库记录了本人备考 **CCF CSP（计算机软件能力认证）** 的过程，最终认证成绩：**300 分**。

> 备考阶段主要针对**第三题（大模拟）** 做专项练习，这也是仓库中题目最集中的部分。

## 项目说明

- 目录按 **CCF CSP 认证场次** 组织，命名为 `第N次/`（即 CCF CSP 第 N 次认证）。
- 每个场次下再按题号建立子目录，命名为 `N_题号/`（例如 `40_3` 表示第 40 次第 3 题）。
- 大部分题目都附带了：
  - 📄 **题目原文**：PDF 或题面截图（`*.pdf` / `*.jpg`）；
  - 🧪 **样例数据**：样例输入与参考输出（`*.in` / `*.ans`，部分为官方测试数据 `*.zip`）；
  - 💻 **我的题解**：C++ 源码（`*.cpp`）；
  - 📝 **部分题目的笔记**：踩坑与思路记录（`*.md`，例如《为什么会 TLE 和 WA？》）。
- 编译产物（`*.exe`、`output/` 目录）已通过 `.gitignore` 忽略，不纳入版本管理。
